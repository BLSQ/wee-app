# Dark Mode Implementation Plan

> **For agentic workers:** Implement directly in this session with superpowers:executing-plans
> (CLAUDE.md forbids subagent-driven development). Steps use checkbox (`- [ ]`) syntax.

**Goal:** A header button switches the dashboard between light and dark, following the OS by default.

**Architecture:** Mantine's built-in color scheme manager (localStorage) with `defaultColorScheme="auto"`.
A `ColorSchemeToggle` in `src/ui/` renders both icons and lets Mantine's CSS hide one, so SSR markup is
scheme-independent.

**Tech Stack:** Mantine 9, `@tabler/icons-react`, TanStack Start, Vitest, `react-dom/server`.

**Spec:** `docs/superpowers/specs/2026-09-17-dark-mode-design.md`

## Global Constraints

- Shell work: touch neither `src/features/router.ts` nor `src/features/nav.ts`.
- No mocks, no new test dependencies (no jsdom, no testing-library).
- Button label is exactly `Toggle color scheme`.

- [ ] **Step 4: Implement** — `src/ui/ColorSchemeToggle.tsx`:

```tsx
import { ActionIcon, Box, useComputedColorScheme, useMantineColorScheme } from '@mantine/core'
import { IconMoon, IconSun } from '@tabler/icons-react'

// Both icons are always rendered; Mantine's CSS hides the one that does not
// match the scheme, so server markup never depends on it.
export function ColorSchemeToggle() {
  const { setColorScheme } = useMantineColorScheme()
  const computed = useComputedColorScheme('light', { getInitialValueInEffect: true })

  return (
    <ActionIcon
      variant="default"
      size="lg"
      aria-label="Toggle color scheme"
      onClick={() => setColorScheme(computed === 'dark' ? 'light' : 'dark')}
    >
      <Box component={IconMoon} size={18} stroke={1.5} darkHidden />
      <Box component={IconSun} size={18} stroke={1.5} lightHidden />
    </ActionIcon>
  )
}
```
